Output Formats: dotnet-api-recon

This guide describes each output type generated by the recon script.

📂 Files Created

Output files are stored in the current directory with a prefix:

recon_<YYYY-MM-DD_HHMM>.*

📄 recon_*.json

Raw data dump

Includes all metadata: method, status code, headers, wordlist match

Useful for chaining into scripts or JQ parsing

📄 recon_*.csv

Clean CSV table

Columns: method, url, status_code, length, words, lines, duration

Ideal for importing into Excel, Splunk, or SIEMs

📄 recon_*.html

Colorized table with JavaScript sorting/filtering

Can be opened directly in browser

Useful for sharing with non-technical stakeholders

📄 recon_*.burp-requests.txt

Raw HTTP requests in Burp-compatible format

Can be imported into BurpSuite using: Project → Import → Paste HTTP requests

Used for replaying or extending test chains

📄 recon_*.nuclei.txt

Results from running Nuclei on discovered paths

Only generated if Nuclei is available in $PATH

✅ Example Usage

To convert JSON to filtered paths:

jq -r '.[] | select(.status_code==200) | .url' recon_*.json
